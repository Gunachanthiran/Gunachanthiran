<img src="https://img.shields.io/badge/OpenAPI_3.0-6BA539?style=for-the-badge&logo=openapiinitiative&logoColor=white"/>

- Full-stack web app with a REST API and an auto-generated OpenAPI 3.0 schema (drf-spectacular) — track expenses, monthly bills, and attendance, then see who pays whom each month.
- **Deterministic settlement engine:** pools shared expenses and splits by days-present weighting plus per-bill rules (equal / days-present / room-share), using largest-remainder rounding so every allocation reconciles to the exact total with no lost cents. Settlement numbers are never stored, so they can't drift.
- **Tested hard:** 132 automated tests across settlement invariants, rounding, presence weighting, role permissions, and full API lifecycle — ~100% line coverage on the REST layer, plus an importable Postman / Bugasura collection.
- **Secured:** role-based access control (Person / Manager / Admin), token + session auth, per-endpoint write-permission checks; production hardening with env-driven config, WhiteNoise, and HTTPS / HSTS / secure cookies.
